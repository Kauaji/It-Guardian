# Planta Baixa

A Planta Baixa representa a localização física; o Mapa de Rede representa relações lógicas. A implementação atual permite construir o espaço manualmente ou usar uma imagem protegida como fundo, sem apagar o editor 2D/3D existente.

O guia completo de upload, componentes, vínculos, camadas, resumo, mapas de calor, permissões e limitações está em [MAPA-INFRAESTRUTURA.md](./MAPA-INFRAESTRUTURA.md). A operação detalhada do editor permanece em [EDITOR-DE-PLANTAS.md](./EDITOR-DE-PLANTAS.md).
